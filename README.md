# IAIP (Interactive Academic Portfolio) & Pharmacy Tech Projects

Welcome to the Interactive Academic Portfolio (IAIP). This repository contains a professional digital portfolio showcasing expertise in pharmaceutical formulation and development, alongside a collection of interactive programming projects that blend healthcare themes with software development.

It also serves as a platform to host future digital healthcare projects, such as upcoming avatar-based educational pharmacology videos designed for medical students.


## 📂 Repository Contents

### 1. Interactive Academic Portfolio (`Portfolio/`)
A comprehensive, responsive web portfolio designed for a pharmaceutical professional.
*   Built entirely with HTML, CSS, and JavaScript, featuring a fully functional dark and light mode toggle[cite: 4].
*   Includes a built-in "Admin Mode" (default password: `admin123`) that allows live editing and addition of skills, publications, and timeline events directly from the browser[cite: 4].
*   Showcases core competencies such as formulation development, QA/QC, and analytical testing, alongside peer-reviewed publications and conference achievements[cite: 4].

### 2. Pharmacy Tic-Tac-Toe (`Task_1-TicTacToe/`)
A medical twist on the classic game of Tic-Tac-Toe.
*   Developed as a single-page web application using HTML, CSS, and JavaScript[cite: 2].
*   Replaces the traditional X and O with a unique "Tablet vs Capsule" theme[cite: 2].
*   Features an active game history tracker, win counters, and dynamic turn indicators[cite: 2].

### 3. ShieldPharma Finance System (`Task_2-Online Banking System (GUI)/`)
A desktop GUI application simulating a corporate banking environment for pharmacy partners.
*   Built with Python, utilizing `tkinter` for the user interface and `sqlite3` for local database management[cite: 1, 5].
*   Features a secure account registration and login system with password validation[cite: 1, 5].
*   Includes a comprehensive dashboard where users can deposit funds, withdraw funds, and view a color-coded, filterable transaction history[cite: 1, 5].

### 4. Med-Snake Game (`Task_3- Snake Game/`)
An interactive desktop game that puts a healthcare spin on the classic arcade Snake.
*   Developed in Python using the `tkinter` library[cite: 3].
*   Players control a snake that consumes standard "pills" to grow and increase their score[cite: 3].
*   Features screen-wrapping mechanics and randomly spawning "high-dose syringe" power-ups that grant bonus points if collected before their timer expires[cite: 3].

## 🛠️ Installation & Usage Instructions

### Web Projects (Portfolio & Tic-Tac-Toe)
No installation is required. These are built with standard web technologies.
1. Navigate to the respective folder (`Portfolio/` or `Task_1-TicTacToe/`).
2. Double-click the `index.html` file to open it in your default web browser.

### Python GUI Projects (Online Banking & Med-Snake)
To run these applications, you must have **Python 3.x** installed on your system.
1. Clone or download this repository to your local machine.
2. Open your terminal or command prompt.
3. Navigate to the specific task directory.
4. Run the Python scripts using the following commands:
   * **For ShieldPharma Finance:** `python online_banking.py` (or the specific filename for Task 2).
   * **For Med-Snake:** `python med_snake.py` (or the specific filename for Task 3).
5. **Note:** Both Python scripts utilize `tkinter` and `sqlite3`, which are included in Python's standard library. No additional `pip` installations are required.
